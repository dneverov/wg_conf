# wg_conf

Copies Amnezia WG configuration files.

## How To Use:

```bash
ruby copy.rb ConfigFileName.conf
```

Or
```bash
ruby copy.rb ConfigFileName.conf NewFileName.conf
```

E.g.
```bash
ruby copy.rb SerbiaBelgradeS3.conf wg2_ser_bel_S3.conf
```
